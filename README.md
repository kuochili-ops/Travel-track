𓃥 白六旅遊軌跡記錄 (Travel Track 3D)
一個極致視覺化、流暢且具沉浸感的 3D 球體漫遊旅程動畫網站。透過 8K 高解析度地球質感、真實道路路徑匹配與 HTML/2D 精確視訊空間標籤 Overlay，將您的旅行軌跡記錄轉化為電影般的漫遊動畫。
👉 立即體驗網頁版 (Demo)
✨ 核心特色與亮點
￼ 🌍 8K 精確球體投影：採用 8K 高畫質海洋與陸地地貌貼圖，配合大氣層渲染，視覺效果生動逼真。
￼ 📍 精確視訊座標標籤 (HTML 2D Overlay)：
￼ 地名與日期卡片 100% 精確錨定在 3D 站點正上方。
￼ 完全解決 3D WebGL 文字貼圖模糊或在行動端瀏覽器被裁剪隱藏的問題。
￼ 支援 0.4 秒平滑淡入淡出 (Fade in / Fade out) 切換效果。
￼ ⏱️ 智慧旅程滯留與動態轉場節奏：
￼ 當同一地點既是上段終點又是下段起點時，交通工具抵達後會在原地停留 2 秒（維持顯示「🏁 到達地點」標籤）。
￼ 滯留 2 秒後，自動切換顯示下一段的「🚀 出發地點」標籤，並在原地預備 1 秒 後繼續啟動出發。
￼ 🚗 多樣化交通工具與道路匹配：
￼ 汽車 / 巴士 / 火車：支援整合 OpenStreetMap (OSRM) 實時抓取真實陸路道路軌跡。
￼ 飛機 / 渡輪：動態繪製大圓拋物線與曲面航線。
￼ 支援多節火車車廂連體與車頭獨立轉向演算法。
￼ 🔗 一鍵生成短網址分享：
￼ 將完整的行程資料壓縮並編碼至網址參數中，免傳資料庫即可透過專屬短網址分享給朋友。
🛠️ 頁面選單與操作說明
選單項目
功能說明
新增行程記錄
輸入交通工具、出發與到達地點名稱及日期，系統會自動非同步解析地理座標。
管理與修改行程
檢視所有已建立的行程段落，支援修改、刪除與標記「跨日」行程。
分享短網址
自動壓縮行程數據並產生專屬短網址，朋友點開即可觀看您的完整軌跡。
解鎖/跟隨視角
自由切換「跟隨交通工具鏡頭」與「自由旋轉縮放地球視角」。
進度條與倍速
支援手動拖曳進度條快轉/倒帶，並可切換 1x / 2x / 5x 播放速度。

🚀 部署指引 (GitHub Pages)
本專案為純前端單一檔案應用程式（Single Page Application），不需要建置工具，直接放置於靜態伺服器即可運作。
🧰 技術棧 (Tech Stack)
￼ 渲染引擎：Three.js (r128) & OrbitControls
￼ 地理資料處理：D3.js (d3-geo) & TopoJSON Client
￼ UI 框架與圖示：Tailwind CSS & FontAwesome 6
￼ 地理編碼與路由：OpenStreetMap (Nominatim API & OSRM Routing API)
